# Один проход: явные числовые компоненты

18 октября 2026 проверен один кандидат без дальнейшего подбора по результатам.
Критерий до проверки: минимум 20 дополнительных строк orders.csv с четырьмя верными
числовыми полями и ни одной новой числовой регрессии на CSV и прежнем размеченном наборе.

После native+CRF ядро проверяет отдельные компоненты, разделённые запятой, точкой с
запятой или переносом. Компонент должен содержать ровно один маркер роли и одно число.
Поддержаны оба порядка, склейки, русские/казахские обозначения и варианты транслита.
Словарь содержит роли, а не названия населённых пунктов или готовые адреса.
Числа внутри выделенных улиц/ориентиров защищены. Свободный текст инструкций не
сканируется как отдельные пары. Существующие значения сохраняются; исключение —
точная путаница корпуса с домом: `148 корп 2` при исходном house=2 даёт house=148.
При конкурирующих явных значениях новые предложения не применяются; результат
получает предупреждение о конфликте и статус needs_review.

Обогащение записывает источник в `normalization_details.explicit_components`, версия
результата с добавлением — `native-explicit-components-v1`. Confidence сохраняет оценку
native evidence; это не новая калибровка вероятности. Модели и справочники не менялись.

## Извлечение из 200 адресов CSV

Эталон чисел составлен LLM по исходному тексту до сравнения. Это не внешняя проверка
существования адресов. Корпус сохранён в исходной строке; дробный дом не разделяется
на дом и квартиру без явного основания. Частные записи не включены в репозиторий.

| Явно присутствующее поле | До прохода | После |
|---|---:|---:|
| Дом | 150/200 | 179/200 |
| Квартира | 124/180 | 179/180 |
| Подъезд | 20/120 | 113/120 |
| Этаж | 63/200 | 195/200 |

Все четыре числовых поля одновременно, включая правильное отсутствие:
**40/200 → 171/200**. Исправлены 309 отдельных полей, числовых регрессий 0.

## Прежний корпус

Проверены 4608 строк, из них 4544 имеют числовую разметку. Все четыре числовых поля:
**3268/4544 → 3710/4544**. Исправлено 981 поле, новых числовых ошибок 0.
64 строки без числовой разметки не засчитаны в качество. Корпус включает диагностические
и ранее использованные при обучении данные; результат не является независимой
оценкой на реальных доставках. Географическая точность этими числами не измеряется.
На всех 4808 строках география, улицы, ориентиры, координаты и статусы сохранились.

Локальные воспроизводимые артефакты: `.artifacts/explicit-components-pass/` — исходные
результаты, неизменённые эталоны, score.py, изменения полей, проверки HTTP и manifest.

## Проверка выпуска

Собранный native HTTP API совпал с ожидаемыми результатами на всех 4808 строках.
После подключения на jana.linker.kz повторная проверка всех 4808 строк подтвердила
паритет, включая поля, metadata, предупреждения и confidence (допуск 1e-12).
Публичные пакеты по 1000 строк: 1,98–3,42 с. Проверены desktop и 390×844 в браузере:
обратный порядок маркеров, отображение квартиры/подъезда/этажа и исправленный дом
перед корпусом. Проверка не подтверждала синтетические здания в каталог.

Откат: образ `jana-showcase-api:rollback-before-explicit-components`; рабочий volume
не заменялся. Сохранённые задания для нового результата следует запустить заново.
На этом один согласованный проход завершён.
