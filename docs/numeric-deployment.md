# Развёртывание числового слоя v0.2.0

Основной pipeline — native libpostal, правила и справочники. Числовой CRF-сервис
дополняет пустые house/apartment/entrance/floor по проверенной политике. При его
отказе API возвращает baseline. Confidence остаётся эвристикой native-разбора.

## Локальный стенд

`make demo` собирает отдельный проект `jana-hackathon`. Подробности и команды
офлайн-запуска: [сценарий показа](hackathon-demo.md).
Модель закреплена в [backend/numeric](../backend/numeric/README.md), проверяется
по SHA-256 и не требует локальных лабораторных образов или весов вне Git.
Зависимости скачиваются при сборке; при запуске загрузок нет.

## Публичный стенд

`scripts/showcase.sh` использует `compose.yaml`, `compose.numeric.yaml` и
`compose.showcase.yaml`. Runtime-сеть изолирована от интернета; только tunnel
имеет внешнее подключение. Для обновления после подготовки приватного конфига:

```sh
make showcase
make showcase-status
```

[Настройка стенда](../deploy/showcase/README.md). Старый contextual runtime в этот
релиз не входит. Его исходники доступны по тегу
`snapshot-before-hackathon-cleanup-20261018`. Автодеплой включается отдельно
через `make showcase-watch`; для фиксированного показа используйте явное обновление.

## Отказ и откат

`NUMERIC_SUPPLEMENT_URL` включает дополнение; пустое значение отключает его.
При отказе сервиса нормализация продолжает работать на native baseline.
Не используйте одновременно `CONTEXTUAL_NORMALIZER_URL` и числовой слой.
Сохраняйте отдельные теги проверенных образов перед обновлением. Для отката
используйте предыдущий совместимый образ backend и отключите числовой URL.
Не заменяйте рабочий том архивом автоматически: это затрёт новые действия операторов.
Старые задания не пересчитываются; для новой обработки отправьте пакет заново.
