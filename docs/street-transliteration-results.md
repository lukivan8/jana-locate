# Обозначения улиц и транслитерация — 18 октября 2026

Исправлен класс ошибок `Karaganda, ulitsa Alalykina 12`: результат содержит
`street_type: улица`, `street_name: Алалыкина`, `house: 12`. Проверены также
`ul. Alalykina` и `Almaty, ulitsa Kurilskaya 9 kv1`.

В выделенном libpostal компоненте улицы отделяется полный токен типа (`ulitsa`,
`ul.`, `prospekt`, `pereulok` и сокращения). Написание названия восстанавливается
по целому компоненту через отдельный индекс транслитераций справочника и совместимый
контекст населённого пункта. Все совпадающие идентичности сохраняются; разные
канонические названия не сводятся к произвольному победителю. Неизвестные названия
сохраняются. Справочник не содержит готовых ответов на адресные строки.

Индекс используется явно через `LatinExact`; обычный поиск географии, разрешение
районов и `Exact` не расширялись. Первый широкий вариант отклонён после обнаружения
потери числовых дополнений при новых неоднозначностях. Он не развёртывался.

На одинаковых 4608 диагностических адресах рабочий baseline сравнен с изолированным
API кандидата: изменились 62 строки — 36 значений типа улицы и 58 названий (срезы
пересекаются). Остальные адресные поля, статусы, предупреждения и координаты совпали;
confidence сохранился с допуском 1e-12. Это сравнение поведения, не независимая оценка
точности всей нормализации. Пакеты по 1000 через изолированный HTTP API: 1,32–2,33 с;
последние 608: 1,09 с. Контейнер уложился в ограничение 3 ГиБ (наблюдалось около 2,34 ГиБ).

Проверки: `go test -race ./...`, `go vet ./...`, полные тесты Docker-сборки с native
libpostal, контрастные и отрицательные случаи. Артефакты воспроизведения и отклонённых
вариантов: локальный игнорируемый каталог `.artifacts/street-translit-review/`.

Откат публичного backend: тег `jana-showcase-api:rollback-before-street-translit`.
Рабочее хранилище при обновлении не заменяется. Сохранённые задания нужно запустить
заново, чтобы получить новый разбор.

Исправление подключено на jana.linker.kz. Все 4608 публичных HTTP-результатов совпали
с проверенным кандидатом (confidence с допуском 1e-12, порядок предупреждений не учитывается).
В браузере на desktop и 390×844 проверены тип `улица`, название `Алалыкина`, дом `12`
и отображение 71%; ошибок console/runtime не обнаружено.
