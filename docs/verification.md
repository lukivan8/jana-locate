# Проверки публичной версии

[Документация](README.md) · [Как внести изменение](../CONTRIBUTING.md)

Результаты GitHub Actions видны в [проверках приложения](https://github.com/lukivan8/jana-locate/actions/workflows/ci.yml) и [проверках документации/HTTP-примеров](https://github.com/lukivan8/jana-locate/actions/workflows/docs.yml). Статус отдельного запуска относится только к его commit.

Для локальной проверки перед публикацией используется отдельное временное хранилище; рабочие базы и адреса не затрагиваются.

| Уровень | Проверка |
| --- | --- |
| Backend и CLI | Go race-тесты, vet, независимая сборка |
| Контракты | Генерация и равенство принятых снимков OpenAPI |
| Frontend | Build, typecheck, Playwright против временного API |
| Пользовательский сценарий | Нормализация, правка, сохранение, восстановление и экспорт; desktop и mobile |
| Контейнеры | Изолированные Compose-проекты, перезапуск и сохранение данных |
| Offline | Запуск подготовленных образов во внутренней Docker-сети |
| Документация | Локальные ссылки и примеры JavaScript/Python/Go против временного API |

Эти проверки подтверждают работоспособность сценариев и технические инварианты. Они не измеряют точность на реальных адресах и не заменяют оценку качества на независимом наборе.

## Локальная проверка оформления от 17 октября 2026

- Backend и CLI: race-тесты и vet прошли.
- Frontend: build/typecheck и 23 Playwright-сценария прошли, включая desktop/mobile, сохранение, конфликт ревизий, восстановление и экспорт.
- HTTP-примеры JavaScript/Python/Go дали одинаковый полный ответ актуального API.
- Docker smoke и offline smoke прошли с временными томами и проверкой восстановления после перезапуска.
- CLI smoke прошёл: временный PostgreSQL, исходные ключи, правки, публикация, перезапуск и 16 браузерных тестов desktop/mobile.
- Вручную проверены пакет, правка и восстановление на 1440×1100 и 390×844; framework overlay и browser errors отсутствуют, горизонтального переполнения страницы нет.

В тесте названия магазина уточнён явный маркер «проспект Туран»: расширенный КАТО также содержит село Туран. Проверка исключает влияние омонима и продолжает проверять, что название магазина не становится населённым пунктом. Правила нормализации для этого не изменялись.

## Готовые контейнеры 0.1.0

- Образы API, web и CLI опубликованы в GHCR; теги `0.1.0` и `latest` доступны без авторизации. Проверен анонимный `docker pull` API и прямой `docker run` с native-нормализацией.
- Публичный релиз содержит те же Docker-образы в архивах с SHA-256. Проверена установка CLI из архива без Docker/GitHub-авторизации, включая проверку контрольной суммы и `docker load`.
- Установщик проверен для web/full: запуск без сборки, локальная нормализация, экспорт файла и сохранение данных после down/up.
- Режим hosted проверен отдельно: локальный CLI вызывает `https://jana.linker.kz`, нормализатор локально не запускается.
- `make check`, `make smoke`, `make offline-smoke` и `make cli-smoke` прошли. На готовом web/API-комплекте прошли 23 Playwright-теста; CLI/PostgreSQL — 16 браузерных тестов.
- Команды установки, переключение комплекта и копирование проверены на 1440×1000 и 390×844; браузерных ошибок и переполнения страницы нет.

В CLI-тесте навигации заменено ожидание удалённой ссылки «Тестовый запуск» на действующую кнопку «Новый запуск». Поведение приложения и содержимое выпущенных образов для этого не менялись.
