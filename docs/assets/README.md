# Иллюстрации проекта

- `banner.svg` — векторный баннер для README, без внешних шрифтов и скриптов.
- `workspace.png` — реальный интерфейс на синтетических адресах, резервный режим с подготовленным справочником и без native libpostal. Это иллюстрация сценария, не измерение качества.
- `social-preview.svg` — исходник карточки ссылки.
- `social-preview.png` — карточка 1280×640 для GitHub Social preview; файл меньше 1 MB.

Карточка ссылки настраивается в Settings → General → Social preview → Edit → Upload an image. GitHub не устанавливает её автоматически по имени файла в репозитории. [Официальная инструкция](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

Перед обновлением скриншота запускайте приложение с отдельным временным хранилищем. Не используйте реальные адреса, рабочие задания, пароли и профили подключения.
