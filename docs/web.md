# Проверка адресов в браузере

[Документация](README.md) · [Запуск интерфейса](quickstart.md)

## Загрузка и обработка

Откройте `http://localhost:3000`. Вставьте адреса или загрузите файл через форму. Для JSON используются записи `{id, raw_address}`: массив либо объект с `records`. Пример — [request.json](../examples/http/request.json). В интерфейсе также доступны импорт таблиц и выбор адресной колонки.

Запустите обработку. Сервер сохраняет пакет как задание до нормализации. Строки с недостаточными данными и конфликтами остаются в очереди; они не исчезают из экспорта.

## Проверка записи

Откройте запись и прочитайте исходный адрес, выделенные поля и предупреждения. Если название населённого пункта неоднозначно, изучите совместимые варианты и выберите нужный только при наличии основания. Нормализатор не должен угадывать город по известности названия.

Исправьте адресные поля и сохраните изменения. Неизвестное значение оставляйте неизвестным. Квартира, подъезд, этаж и ориентир относятся к записи доставки; они не становятся общими значениями здания.

Сохранение исправлений и экспорт — отдельные действия. После правок экспортируйте результат для своей системы. В режиме CLI публикация в PostgreSQL также выполняется отдельно, по явному подтверждению.

## Продолжение работы

Сохраните ссылку на задание. После обновления страницы сервер восстановит сохранённые данные; несохранённый черновик формы не гарантируется. Задания хранятся до семи дней после изменения, максимум 50 заданий / 64 MiB. Для долговременного хранения используйте экспорт или собственный журнал.

При конфликте ревизий не перезаписывайте чужие изменения автоматически: загрузите актуальную версию и согласуйте правку. [Ревизии и ошибки API заданий](../backend/docs/jobs.md).

## Встроенные примеры

В интерфейсе есть набор сложных синтетических адресов. Он помогает познакомиться с обработкой опечаток, сокращений, омонимов и неполных строк. Это не независимый реальный тестовый набор и не доказательство точности.

## Режим CLI

Локальный сайт CLI использует тот же интерфейс, но работает с локальным журналом, снимком БД и отдельным API оркестрации. Доступы к PostgreSQL остаются у CLI. Результаты публикуются в отдельную таблицу; исходная колонка не изменяется. [Полное руководство](../cli/README.md).
