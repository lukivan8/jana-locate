# Исправление полной формы «город», 18 октября 2026

Класс ошибки: libpostal возвращал `город Караганда` как city, а справочник содержал
`г.Караганда`. Несовпадение препятствовало выбору сущности и дополнению области.

В индексе immutable-справочника при загрузке создаётся полная форма `город …`
только из существующего квалифицированного алиаса `г.…`. Это преобразование
компонента адреса для всех записей, без исключений по названию города, raw_address
или ID. Исходная SQLite и веса обеих моделей не меняются.

Проверки ролей защищают от двух побочных эффектов: название города внутри
компонента с префиксом заведения не становится географией; после разрешения
полной формы города его двуязычный алиас не становится улицей без сигнала парсера.
Голое название Караганда сохраняет совместимые городские и сельские сущности.

Первая экспериментальная версия расширяла также с./п. и была отклонена:
она затрагивала отдельные сельские неоднозначности и числовое дополнение.
В выпуск включено только раскрытие г. → город. Более широкое исправление ролей
также сужено до квалифицированных городских упоминаний, чтобы не менять весь baseline.

Артефакты эксперимента: `.artifacts/normalization-lab/goal/settlement-qualifiers/`.
Там сохранены исходный публичный результат, контрастные входы, сырые результаты
каждой версии, сравнение 4608 строк, логи native Docker tests, race/vet и manifest.

Окончательная проверка: 4608 строк, изменились 14. Все изменения просмотрены:
канонизация city, дополнение области, удаление ошибочного жилого массива и
соответствующее изменение предупреждений/оценки. Новых регрессий не обнаружено;
все house/apartment/entrance/floor совпали с предыдущим выпуском. Дополнительно
23 контрастных входа по шести городам и отрицательным случаям. API-пакеты по 1000
в изолированном свежем сервисе заняли 1.39–2.36 секунды после готовности.
`go test -race ./...`, `go vet ./...` и native Docker tests прошли.

Предыдущий публичный API сохранён как `jana-showcase-api:rollback-before-city-qualifier`.
Модель числового дополнения остаётся прежней. Изменения не затрагивают рабочее
хранилище и API-контракт. Для старого задания требуется повторная отправка адреса.

Выпущено на jana.linker.kz. Повторный публичный прогон 4608 строк совпал с
проверенным кандидатом: 0 различий по контрактным полям/решениям. Проверены
браузерные desktop/mobile сценарии: «город Караганда» и «г.Караганда» дают 94%,
область и чистое название; голая Караганда сохраняет проверку и альтернативы.
Ошибок браузерной консоли не обнаружено.
