# Веб-интерфейс Jana Locate

Самостоятельная TanStack Start SPA для нормализации, проверки и экспорта адресов. Сборка не требует исходников Go или работающего API. Все запросы выполняются браузером через `src/api/client.ts`.

## Разработка

Нужен Node 22.12+:

```sh
npm ci
VITE_JANA_API_URL=http://localhost:8080 npm run dev
npm run build
npm run typecheck
```

## Docker

Из этого каталога:

```sh
docker build -t jana-locate-web .
docker run --rm -p 127.0.0.1:3000:8080 \
  -e JANA_API_URL=http://localhost:8080 jana-locate-web
```

Nginx обслуживает только `dist/client`. HTML-оболочка собирается без обращений к API. SPA-маршруты используют fallback `/_shell.html`; Node в production не запускается.

`JANA_API_URL` записывается в `/config.js` при старте контейнера и должен быть доступен браузеру. В dev используется `VITE_JANA_API_URL`, затем `http://localhost:8080`. API должен разрешать точный origin интерфейса. При HTTPS используйте HTTPS и для API. Конфигурация браузера публичная и не должна содержать секреты.

## Контракт

`src/api/openapi.json` — самостоятельная копия контракта, `schema.gen.ts` генерируется закреплённым `openapi-typescript`. Для обновления из работающего API:

```sh
JANA_API_URL=http://localhost:8080 npm run contract:pull
npm run contract:generate
npm run build
npm run typecheck
```

Проверяйте diff контракта до внедрения. Сборка сама его не скачивает. `openapi-fetch` проверяет типы запросов при компиляции, а не валидирует ответы во время исполнения.

## Проверка и экспорт

Можно вставлять адреса построчно или загружать массив / `{"records":[...]}` с `id` и `raw_address`. Предел — 1000 записей и тело 2 MiB. Исходные ID и строки сохраняются; результат экспортируется как `{"results":[...]}`.

Неизвестные поля, конфликты и синтетические координаты явно показаны. Подтверждение сохраняет только здание и проверенные координаты через API. Детали доставки сохраняются в текущем экспорте; перезагрузка сбрасывает локальную сессию. Изменение ключевых полей создаёт другое здание, конфликт ревизии требует перечитывания.

Встроенные 161 сложный пример — синтетические входные строки, без ожидаемых ответов и заявлений о точности. Их JSON можно загрузить в основной поток. Генерация: `python3 scripts/generate-anomaly-fixtures.py`.

## Проверки

Используйте API с отдельным временным overlay: тесты подтверждают синтетическое здание.

```sh
npx playwright install chromium
npm run test:e2e
```

`JANA_TEST_API_URL` выбирает тестовый API; он должен разрешать `http://localhost:3000`. Темы светлая/тёмная, локальные шрифты и карта без внешних тайлов позволяют работать offline. Цветовые роли и компоненты находятся в `src/ui/`; `npm run theme:generate` обновляет палитру.
