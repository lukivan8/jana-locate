# Jana Locate

**Готовый сервис нормализации адресов Казахстана: HTTP API, веб-интерфейс и CLI для файлов и PostgreSQL.** Превращает свободный текст в населённый пункт, область, район, улицу, дом, квартиру, подъезд и этаж. Подключается к вашему приложению по HTTP или запускается локально готовым комплектом.

## Локальный запуск

Нужны Docker Engine/Desktop с Compose v2, `curl` и shell. Команда та же, что в блоке установки на сайте:

```sh
curl -fsSL https://raw.githubusercontent.com/lukivan8/jana-locate/main/scripts/install.sh | sh -s -- full
```

Установщик скачает готовые контейнеры **v0.3.2** и запустит **API + Web + CLI** вместе с моделями и справочниками. Компилировать проект и устанавливать Go, Node.js или Python не требуется.

- **Веб-интерфейс:** [localhost:8095](http://localhost:8095).
- **API:** `http://localhost:8080`.
- **OpenAPI:** [localhost:8080/openapi.json](http://localhost:8080/openapi.json).

После установки нормализация работает **без интернета, внешних AI API и ключей**. Данные остаются на вашей машине. Остановка с сохранением данных — `cd jana-locate && ./jana down`, повторный запуск — `./jana up`.

[Другие варианты установки](docs/quickstart.md) · [Релизы и исходники](https://github.com/lukivan8/jana-locate/releases)

## Batch-запрос: локально или в облаке

Выберите адрес API. Формат запроса одинаков для обоих вариантов:

```sh
JANA_API_URL=http://localhost:8080
# Для облачного API вместо строки выше: JANA_API_URL=https://jana.linker.kz

curl --fail-with-body --max-time 310 "$JANA_API_URL/v1/normalize" \
  --header 'Content-Type: application/json' \
  --output batch-results.json \
  --data-binary @- <<'JSON'
{
  "records": [
    {"id": "order-1", "raw_address": "Астана, проспект Туран 55/6 кв 99"},
    {"id": "order-2", "raw_address": "Алматы, улица Абая 10, подъезд 2, этаж 3"}
  ]
}
JSON
cat batch-results.json
```

Передавайте до **1000 записей за запрос**. Ответ `{"results":[...]}` содержит структурированные поля, `status`, `confidence` и `warnings` для каждой записи, сохраняя **ID, исходную строку и порядок**. Примеры выше демонстрационные; замените их своими адресами. При выборе облачного API строки отправляются на `jana.linker.kz`.

[Контракт OpenAPI](backend/api/openapi.json) · [Поля ответа](backend/docs/consumer-guide.md) · [Примеры JavaScript, Python и Go](examples/http/README.md)

## Как проходит нормализация

1. **Подготовка текста.** Исходная строка сохраняется; рабочая копия очищается от лишних пробелов и невидимых символов.
2. **Разбор адреса.** libpostal выделяет компоненты, правила дополняют их по обозначениям дома, квартиры, подъезда и этажа.
3. **Согласование с Казахстаном.** КАТО и OSM помогают сопоставить названия и варианты написания, согласовать область и населённый пункт, дополнить район по связям улиц и домов. Подготовленный снимок содержит **66 339 сущностей и 1 078 711 адресных свидетельств**.
4. **Числовое дополнение.** В локальном комплекте и публичном API собственная CRF-модель с весами около **211 КиБ** дополняет пустые числовые поля по контексту. Например, `41 пәтер; 2 кіреберіс; 4 қабат` даёт квартиру 41, подъезд 2 и этаж 4.
5. **Результат и проверка.** API возвращает JSON, а веб-интерфейс позволяет проверить спорные записи, выбрать населённый пункт, исправить поля и экспортировать результат. Задания и исправления сохраняются между сессиями.

## Почему Jana Locate

- **Plug-and-play.** Готовый комплект от установки до проверки и экспорта: API, интерфейс, CLI, модели и справочники запускаются одной командой.
- **Адаптация к Казахстану.** Международный парсер дополнен КАТО, OSM, локальными обозначениями и собственной числовой моделью.
- **Автономность и контроль данных.** Локальная обработка без облачных зависимостей; облачный API доступен для быстрого подключения без собственного сервера.
- **Интеграция по стандартному HTTP.** Batch API и OpenAPI, примеры на JavaScript, Python и Go — сервис можно подключить к существующему стеку.
- **Работа с накопленными данными.** Импорт TXT, JSON, CSV и XLSX в интерфейсе, обработка файлов и PostgreSQL через CLI, явная публикация результатов в связанную таблицу.
- **Проверка встроена в процесс.** Сохранённые задания, выбор вариантов по справочнику, правки оператора и JSON-экспорт доступны в одном интерфейсе.
