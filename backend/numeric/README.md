# Компактный числовой слой

CRF дополняет пустые числовые поля native-пайплайна. Существующие значения,
географические кандидаты, предупреждения, статус и native confidence сохраняются.
При отказе слоя API возвращает исходный native-результат. Числа в признаках
маскируются; поиска ответа по полной строке или ID нет.

Модель обучена на 3540 ранее допущенных и 880 синтетических строках. Это собственный
артефакт проекта под MIT, а не база подтверждённых адресов. Независимая точность
на реальных адресах не заявляется. Данные обучения не читаются при обработке.

Включённая модель `model.crfsuite`: 215988 байт, SHA-256
`1cf4bdc47fbac61c18ebcedc78bd19022eacaff799a38d1bdc75b886c29dabd4`.
Хеш проверяется при сборке и перед запуском. Зависимость: python-crfsuite 0.9.12
(MIT); metadata и лицензия сохраняются в установленном пакете контейнера.

Из корня: `docker compose -f compose.yaml -f compose.numeric.yaml up --build --wait`.
Сборка скачивает зависимости; runtime работает офлайн, во внутренней сети,
с лимитом 128 MiB. XLM-R, PyTorch и вторая копия libpostal не нужны.

Тесты без модели и внешних пакетов: `python3 backend/numeric/test_numeric_recovery.py`.
Поведение слияния, отказы и неоднозначность проверяются Go-тестами backend.
