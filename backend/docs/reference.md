# Справочник КАТО и OSM

Публичный снимок содержит 17 242 сущности: 15 586 записей официального КАТО от 18 сентября 2026 года, 1371 логическую улицу OSM и 285 жилых территорий.

КАТО покрывает Казахстан. OSM ограничен пересечением административной территории Астаны (`name:ru=Астана`, `admin_level=4`) и bbox `[51.00,71.20,51.25,71.65]`. Это не покрытие улиц всей страны. Единственная улица в неполном снимке не доказывает город адреса.

## Сборка

Из корня Go-репозитория:

```sh
make reference
# Эквивалентно:
python3 tools/build_reference.py \
  --input data/reference/entities.jsonl \
  --manifest data/reference/manifest.json \
  --output data/reference/reference.sqlite
```

Команда работает без сети, используя включённые JSONL и manifest. SQLite исключена из Git и собирается также внутри Dockerfile. Конструктор проверяет типы, повторяющиеся ID, ссылки и целостность SQLite, атомарно заменяет файл и делает его read-only.

Задайте `REFERENCE_PATH` при запуске. Go открывает SQLite с `mode=ro&immutable=1`, загружает индекс псевдонимов в память и закрывает SQL-соединение. Для обновления снимка пересоберите файл и перезапустите процесс; не меняйте файл в процессе его загрузки.

## Схема версии 1

- `metadata(key,value)` — версия и manifest источников.
- `entities(id,kind,name,parent_id,city_id,province_id,district_id,street_type,source)` — административные и уличные сущности.
- `aliases(entity_id,alias)` — доступные названия, варианты языка и исторические имена.

Справочник не содержит координат зданий. Он не заменяет seed или overlay и не принимает записи подтверждений. Родительские связи КАТО выводятся из иерархии кодов; сегменты OSM объединяются по логической улице в заданном городе.

## Обновление источников

[`manifest.json`](../data/reference/manifest.json) содержит URL, время снимка, SHA-256 исходников и JSONL, покрытие и атрибуцию. Обновление — явная подготовительная операция вне runtime. Инструменты загрузки и преобразования доступны в [jana-locate/scripts/reference](https://github.com/lukivan8/jana-locate/tree/main/scripts/reference). При переносе нового JSONL переносите соответствующий manifest и проверяйте иерархии, переименования, омонимы и границы покрытия.

## Источники и атрибуция

- [Официальный КАТО](https://stat.gov.kz/ru/classifiers/statistical/21/): источник сохранён в каждой записи и manifest.
- OSM: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).

При распространении производной базы сохраняйте атрибуцию и применимые условия данных. Частные адресные наборы и рабочие подтверждения в публичный снимок не входят.
